# Sample Knowledge Note

## Title

Project Failure Pattern - Vendor Delay and Scope Drift

## Raw Note

The project started with a clear infrastructure modernization goal, but the scope expanded after the second stakeholder meeting. The vendor underestimated integration complexity with the legacy storage environment. Budget approval was delayed by four weeks, and the team continued informal design changes without change control.
